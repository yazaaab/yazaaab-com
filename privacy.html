Privacy Policy — Hermes

Last updated: 2026-09-28

Overview

Hermes is a personal automation tool used by a single individual (the project owner, Ken Allemang). It accesses Google Workspace services — Calendar, Gmail, Drive, Docs, Sheets, and Slides — to surface and edit the owner's own data on demand. This privacy policy describes the data Hermes accesses and how it is handled.

Data Hermes accesses

  • Google Calendar — read events and create/update events at the owner's request.
  • Gmail — read message metadata and content, and compose/send messages at the owner's request.
  • Google Drive, Docs, Sheets, Slides — read and edit files owned by the owner.

No other data is accessed.

How data is handled

  • All data is processed on the owner's personal devices and on a private home server controlled by the owner.
  • No personal data is transmitted to any third party or external service.
  • No personal data is sold, shared, or used for advertising, analytics, or training.
  • Short-lived caches may exist on the owner's home server to support request handling; these are not retained beyond a few hours.

User controls

Because Hermes is used only by its owner, the owner can revoke Hermes' access to their Google account at any time via Google Account permissions. Revoking access immediately disables all data retrieval.
